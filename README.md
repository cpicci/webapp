# Webapp Workspace

Ce dossier porte désormais le fresh start de la webapp Central Parc Immo.

Le but n'est plus de corriger encore une fois un dashboard existant. Le but est de repartir d'une base documentaire propre pour construire une vraie application interne de reprise du travail.

## Situation actuelle
- le code de la webapp existe et fonctionne
- le problème principal n'est plus technique, mais produit et UI
- les passes precedentes ont améliore certains details sans changer la forme du produit de facon suffisante
- la direction active est maintenant : `bureau operateur`, `inbox operateur`, `detail persistant`, `support secondaire`

## Regle de travail
Le prochain build ne doit pas repartir de la page actuelle pour la polir. Il doit repartir de la nouvelle direction documentaire pour reconstruire une application plus credible, plus personnelle et plus orientee traitement.
